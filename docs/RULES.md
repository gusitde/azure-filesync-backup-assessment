| AFS-02 | Sync health | Medium | Files persistently failing to sync | totalPersistentFilesNotSyncingCount > 0 or last sync per-item error count > 0 | Review per-item errors (portal: server endpoint > Errors + troubleshooting; server: FileSyncErrorsReport). | AFS-05 | Registered servers | High | Agent expired, blocked or expiring within 90 days | agentVersionStatus in Expired/Blocked, or agentVersionExpirationDate within 90 days | Update the Azure File Sync agent (Microsoft Update, AfsUpdater.exe or the download center) and enable automatic agent updates (InstallLatest) with a maintenance window. | AFS-09 | Topology | Medium | Server endpoint on the system volume | serverLocalPath starts with C:\ | Move the server endpoint to a data volume. Cloud tiering is not supported on the system volume and OS/pagefile growth competes with the volume free-space policy. | [learn](https://learn.microsoft.com/azure/storage/file-sync/file-sync-planning#considerations-for-windows-file-servers) |
| AFS-10 | Topology | High | Nested or overlapping server endpoints on the same server | one serverLocalPath is a prefix of another on the same serverResourceId | Nested server endpoints are unsupported. | AFS-12 | Identity | Medium | Storage Sync Service authenticates with the storage account key (managed identity off) | storageSyncService.useIdentity is not true | Move to system-assigned managed identities: agent v20+, Azure Arc on on-premises servers, then Set-AzStorageSyncServiceIdentity (grants Storage Account Contributor + Storage File Data Privileged Contributor). | AFS-14 | Networking | High | Storage account firewall blocks the Storage Sync Service | networkAcls.defaultAction = Deny, bypass lacks AzureServices, no resourceAccessRules for Microsoft.StorageSync | Enable "Allow Azure services on the trusted services list" (bypass AzureServices) or add a resource-instance rule for the Storage Sync Service; keep IP/VNet rules for the servers. | AFS-17 | Topology | Info | Sync group has no server endpoint | sync group with 0 server endpoints | Cloud-only sync group: either add the intended server endpoint or remove the group to keep the topology clean. | [learn](https://learn.microsoft.com/azure/storage/file-sync/file-sync-deployment-guide) |
| AFS-18 | Hygiene | Low | No delete lock on the Storage Sync Service | no CanNotDelete lock at the sync service | Add a CanNotDelete lock. | AFS-19 | Identity | Info | Registered server still on certificate (shared key) authentication | service useIdentity = true but server activeAuthType != ManagedIdentity | Give the server a system-assigned managed identity (Arc-enabled server or Azure VM) and re-run Set-AzStorageSyncServiceIdentity for it. | [learn](https://learn.microsoft.com/azure/storage/file-sync/file-sync-managed-identities#after-configuration-next-steps-and-troubleshooting) |
